# A Complete Upgrade

## Channel 
Let people chat in different channels, for the first version, let's do:
Sports
Tech
News
Music
Study

But keep a General as the main channel

## Reply
People can now reply to a specific message.

## Profiles
People can change how their profiles is displayed, it can be not just IP names, but also preferred names, it can also show bios
Let people edit their profile info through a edit button.

## Multi-media support
User should now be able to upload medias, files, documents.
The maximum upload size limit should be 20MB.

## Mobile support
Make sure the content displayed correctly on mobile screen. You should do careful optimization specifically for phone screens.

# UI Design (important!)
For UI design, you should check ui_design_reference, and follow that style closely. Note that it contains some feature that is not included/described, in that case just ignore it. It is for reference only. But you should design your UI with this reference in mind, and keep it as close as possible.
